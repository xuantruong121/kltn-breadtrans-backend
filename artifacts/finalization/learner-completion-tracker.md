# Learner completion tracker

Order: Auth → Listening → Reading → Grammar → Vocabulary/Flashcard → Courses/Lessons → TOEIC →
Writing → Speaking → Entry Diagnostic → Gamification/Shop/Pet/Arena → Plans.
All workflow tests run on the disposable harness (`scripts/qa/finalization-harness.sh`).
